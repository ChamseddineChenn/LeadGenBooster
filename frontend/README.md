# LeadGenBooster Public Website

This folder contains the public-facing LeadGenBooster website, built with React 19, Vite, React Router, Tailwind CSS, and Framer Motion.

## Main sections and flows

- Company and service information
- Industries and case studies
- Blog listing and article pages
- Careers and job details
- Job application submission
- Quotation requests
- Meeting availability and booking requests
- Newsletter confirmation and unsubscribe pages
- Contact forms and enquiry sections

## Local development

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

The admin workspace and Express API are in sibling directories. See the [repository README](../README.md) for the full project overview and setup instructions.
